# Taste of Travel

A simple HTML webpage created as part of my journey to learn and practice HTML5.

## About the Project

**Taste of Travel** is a fictional culinary website focused on exploring international cuisine through recipes and food-related content.

This project is based on a practical HTML exercise and was created to practice the fundamental elements of HTML5.

## Features

* HTML5 document structure
* Headings and paragraphs
* Text formatting
* Quotations
* Ordered and unordered lists
* Images
* Horizontal rules and line breaks
* HTML tables
* Table captions
* Colspan attributes
* Semantic HTML elements
* Basic accessibility practices

## Technologies

* HTML5


## Purpose

The purpose of this project is to strengthen my understanding of HTML5 and practice creating a structured webpage from scratch.

This project will be expanded as I continue learning web development.
