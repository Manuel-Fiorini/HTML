# Harmony Heights – Official Band Page

A simple HTML project created to practice the fundamentals of web development by building an official webpage for the fictional band Harmony Heights.

The project combines different HTML elements to create a multimedia website with information about the band, music, performances, tour dates, social media links, and a contact form.

## Project Overview

The webpage includes:

* Band introduction
* Band and member images
* Audio player
* Video player
* Upcoming tour dates
* Ticket links
* Social media links
* Contact form
* Basic form validation
* Text formatting
* HTML5 multimedia elements

## Technologies

* HTML5
* HTML Forms
* HTML5 Audio
* HTML5 Video
* Basic HTML form validation

## Multimedia

The webpage contains images of the band and its members, an audio track using the `<audio>` element, and a performance video using the `<video>` element.

Both multimedia elements include browser controls that allow users to interact with the content directly from the webpage.

## Contact Form

The page includes a contact form containing:

* Name
* Email
* Phone number
* Message
* Submit button
* Reset button

HTML validation is used to ensure that required fields are completed and that the email and phone number follow the expected format.

## How to Run

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/harmony-heights.git
```

Enter the project directory:

```bash
cd harmony-heights
```

Open the HTML file in a web browser:

```bash
xdg-open harmony-heights.html
```

Alternatively, open `harmony-heights.html` directly with any modern web browser.
