# Sunnydale School Webpage

An enhanced HTML webpage for Sunnydale School, created as part of the Web Development Essentials course.

The project focuses on improving the visual presentation, usability, and interactivity of a basic school webpage using HTML, CSS, global attributes, event attributes, and data attributes.

## Features

- HTML5 document structure
- Custom styling with an internal CSS stylesheet
- Font and color customization
- `id` attributes for specific sections
- `class` attributes for reusable styles
- `data-*` attributes for storing additional information
- `title` attributes for tooltips
- Inline styling with the `style` attribute
- Event handling with the `onclick` attribute
- JavaScript `alert()` interactions
- Styled upcoming events
- Contact information section
- Responsive-friendly HTML structure
