# BLOOM — Indoor Plants

BLOOM is a simple HTML project created as a practical exercise while learning the fundamentals of web development.

The project represents a small online flower shop and focuses on presenting indoor plants in a simple and structured webpage.

## Features

* Indoor plant presentation
* Plant descriptions
* Product prices
* Plant images
* Plant information links
* About Us section
* Contact information
* Email link using `mailto:`
* HTML footer

## Technologies

* HTML5

## Project Structure

```text
BLOOM/
├── index.html

```

## Purpose

This project is part of my HTML learning path and is intended to practice the fundamental concepts of HTML5, including document structure, headings, paragraphs, lists, images, links, attributes, and semantic elements.

The project will be progressively improved as I learn new web development concepts.
